# tai-money

Taï's money notebook as a home-screen app: spending, money coming in, Cash / Wave / Card / Savings, subscriptions and habit trends.

This repo holds only the app's code. Every entry is saved on the phone that uses it (in the browser's storage) and is never sent here or anywhere else. Use **Save a backup** on the Home tab to keep a copy.

The page is built from `expenses.html` in Taï's private Ta-repository (`money-app/build.py`). Edit it there, rebuild, then copy the files here.
